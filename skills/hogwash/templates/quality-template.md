# Quality and style profile

Host agent: replace this guidance with the user's approved standards. The
`idiolect` skill builds this file interview-first when the user has no
samples. This file defines structure, evidence, and the bar for completion. The voice profile defines how the prose sounds.

## Rules for every format

Record checkable requirements for claims, evidence, headings, paragraphs, links, and factual preservation. Separate required behavior from preferences.

## Rules by format

Create one section for each format the user names. Record the target reader, length, structure, evidence requirements, and ending. Do not add formats that the user does not use.

## Completion checklist

Write a short checklist that the host agent can verify against the candidate. Include factual preservation, the intended reader's task, and every approved hard rule.

## Known failure patterns

Name only patterns the user recognizes in their writing. For each pattern, state the observable symptom and the correction.
