# Ban list

Host agent: replace this guidance with literal words and phrases the user
bans. The `idiolect` skill collects bans properly: only the user declares
them, and an observed absence is never a ban. Hogwash reads bullet items as rules. Keep guidance and category notes outside bullets until the user supplies real entries.

Put the banned term first. Put the reason after an em dash, an en dash, or ` - `. Add each banned inflection as a separate bullet.
